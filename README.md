# 电力标准知识服务工具

当前版本支持问题输入、条款检索、模型建议、通用设备/动作模板，以及变电站设备运维模拟。保留原首页及模板管理页布局，在原“操作建议”页签接入明确的模拟下发、状态更新和反馈；知识查询和指令预览不改变状态，真实设备下发保持关闭。

在原首页选择变电站设备运维并提问，可使用7类14台设备、四种工况和通用模板能力。目录保留原有设备并扩充至25台、61项写动作；操作步骤和接口见 [变电站模拟功能说明](docs/变电站模拟工作台.md)。

条款分析后的动作建议也使用通用模板转换，不再要求预先绑定具体条款；保留本次检索的动态引用，以及设备参数、联锁和状态版本检查。普通标准问答不必生成动作。

## 运行环境与启动

项目统一使用Python 3.13。首次下载代码或依赖发生变化后，在PowerShell中运行一次：

```powershell
.\初始化项目环境.ps1
```

日常离线启动只需要：

```powershell
.\启动前端实验.ps1
```

需要调用DeepSeek时，先在项目根目录的`.env`中配置`DEEPSEEK_API_KEY`，然后运行：

```powershell
.\启动前端实验.ps1 -Online
```

运行完整测试：

```powershell
.\运行测试.ps1
```

启动期间终端会显示条款加载、知识图谱构建和前端启动进度；详细日志位于`artifacts/local_demo/`。
