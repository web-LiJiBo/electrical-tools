## 运行环境与启动

项目统一使用Python 3.13。首次下载代码或依赖发生变化后，在PowerShell中运行一次：

```powershell
.\初始化项目环境.ps1
```

日常启动默认使用在线大模型，所有自然语言问题先调用模型接口理解，再由后端读取事实、检索和校验：

```powershell
.\启动前端实验.ps1
```

密钥可在项目根目录`.env`、当前进程、用户或系统环境变量中配置。原有`-Online`参数继续兼容：

```powershell
.\启动前端实验.ps1 -Online
```

仅在明确需要离线演示时运行`启动前端实验.ps1 -Offline`；离线结果不作为真实API有效性验收。在线理解失败、输出缺少问题类型时会提示模型未完成，不静默改用关键词生成操作。状态读取和操作能力仍取自后端目录与快照，查询和预览不改变状态。

运行完整测试：

```powershell
.\运行测试.ps1
```

启动期间终端会显示条款加载、知识图谱构建和前端启动进度；详细日志位于`artifacts/local_demo/`。
