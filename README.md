# 电力标准知识服务工具

当前本地版本支持问题输入、条款检索、模型建议、只读模拟设备事实和协议候选指令生成。流程仅到指令生成，不确认、不下发、不改变模拟设备状态。

## 运行环境与启动

项目统一使用Python 3.13。首次下载代码或依赖发生变化后，在PowerShell中运行一次：

```powershell
.\初始化项目环境.ps1
```

日常离线启动只需要：

```powershell
.\启动前端实验.ps1
```

需要调用DeepSeek时，先在项目根目录的`.env`中配置`DEEPSEEK_API_KEY`，然后运行：

```powershell
.\启动前端实验.ps1 -Online
```

运行完整测试：

```powershell
.\运行测试.ps1
```

启动期间终端会显示条款加载、知识图谱构建和前端启动进度；详细日志位于`artifacts/local_demo/`。

使用、实验样例、原版对比、修改位置、数据路径和验证限制统一见 [代码修改说明](代码修改说明.md)。

指令模板的查询、补充、加载规则及本批22个新增模板，见 [指令模板补充说明](代码修改说明.md#10-指令模板管理与本批补充说明2026-10-12)。默认预置库现有17台模拟设备、41个动作模板；用户自行保存的模板另计。全部仅生成协议示例，不下发设备。

2026-10-12代码、补充条款及模板已推送至main，发布提交为 `17e2e1b0c194fa180bad08bdfb31996cedc073c7`；随后说明更新可能形成后继提交。实际推送和GitHub分支指针已核对。

补充条款发布快照位于 `datasets/supplemental/分解数据/json`，不覆盖原标准库。预置指令模板随 `configs` 发布；API密钥必须由使用者另行配置。

模型调用失败会显示具体原因及各步处理进度，不再把“知识查询”直接解释为无需指令。在线启动先检查接口连通性；最新修改与验证范围见修改说明第11节。
