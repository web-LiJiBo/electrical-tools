## 4. 启动 HTTP 服务并验证

这一步需要额外安装 API 依赖；离线测试通过不代表 API 已启动。

```powershell
& .\.venv\Scripts\python.exe -m pip install -e ".[api,test]"
$env:ELECTRICAL_TOOLS_OFFLINE_UNUSED_KEY = ''
& .\.venv\Scripts\python.exe -m standard_knowledge_service_v2.main --config configs/settings.offline.yaml --serve
```

服务地址为 `http://127.0.0.1:8000`，接口文档为 `http://127.0.0.1:8000/docs`。当前服务只绑定本机；请勿擅自改为公网暴露。停止服务使用 Ctrl+C。

保持服务窗口运行，在另一个 PowerShell 窗口执行：

```powershell
Invoke-RestMethod -Uri 'http://127.0.0.1:8000/health'
$requestBody = @{ query = '什么情况下需要跳闸？' } | ConvertTo-Json
$response = Invoke-RestMethod -Uri 'http://127.0.0.1:8000/analyze' -Method Post -ContentType 'application/json; charset=utf-8' -Body ([System.Text.Encoding]::UTF8.GetBytes($requestBody))
$response | ConvertTo-Json -Depth 30
Invoke-RestMethod -Uri ('http://127.0.0.1:8000/audit/' + $response.request_id)
```

健康检查应返回 `status=ok`、`dispatch_allowed=false`；分析接口应返回结构化结果，审计接口应能按请求编号查到记录。健康检查不检查模型效果，分析返回 HTTP 200 也不等于条件满足或指令可执行。

其他接口：`POST /decompose`、`/search`、`/generate-instruction`、`/validate`、`/generate-report`。分析类请求主要字段为 `query`、`scenario_hint`、`parameters`、`target_protocol`、`conversation_context`；实际接口定义见 `src\standard_knowledge_service_v2\api\routes.py` 和 `schemas.py`。

## 5. 验证条件门禁

实际测量值通过 `parameters` 提供，不是协议配置，也不能仅靠自然语言或相似度分数冒充已确认事实。以下仅是请求结构示例，真实条款还需满足场景、设备映射、约束用途和模板要求：

```json
{
  "query": "生成跳闸候选指令",
  "parameters": {"电流": 120, "额定值": 100},
  "target_protocol": "IEC61850"
}
```

对同一条明确的规则，逐一核对下列行为。可先用 `tests\test_action_preconditions.py` 的合成规则验证，避免真实数据缺少结构化条件导致无法构造正向例子。

| 情形 | 预期 |
| --- | --- |
| 条件明确不满足 | 前置判定 `fail`，控制 `payload` 为空 |
| 缺失事实、条件不可解析或单位未确认 | `uncertain`，控制 `payload` 为空，保留原因 |
| 前置条件全部满足 | 前置判定 `pass`，再进入协议及其他验证，不保证一定生成载荷 |
| 合格的控制候选 | 仍需人工确认，禁止自动下发 |

查看候选里的 `precondition_status`、`precondition_trace`，并结合最终响应状态、验证和证据，不要把三者混为一谈。规则的附加约束必须明确 `constraint_role`：`precondition` 参与动作门禁，`compliance` 用于合规评价，未标明用途会得到 `uncertain`。旧数据未被自动批量标注，这可能限制实际指令生成数量。

无关问题拒答已删除，不应把“拒答无关问题”当成当前验收目标。所有结果中的自动下发仍关闭；此工具不是生产设备控制系统。

## 7. 常见问题与验收边界

| 现象 | 检查方式 |
| --- | --- |
| 找不到包 / PyYAML / pytest | 确认当前项目目录、使用的 Python 路径，以及是否在同一环境执行了安装。 |
| 提示找不到 fastapi / uvicorn | 在启动服务使用的同一环境安装 `.[api,test]`。 |
| 数据目录不存在 / 数量不是 6674 | 检查项目根目录和核验 JSON；不要用空目录代替数据。 |
| 模型密钥缺失或调用失败 | 离线配置降级正常；真实模型模式需排查密钥、网络和返回内容，不输出密钥。 |
| 8000 端口占用 | 停止自己此前启动的同一服务，或另行配置端口；不要终止未知进程。当前命令行没有端口参数。 |
| 条件不满足仍看到候选对象 | 查看 `payload` 是否为空；保留解释对象是正常的，失败/未知时出现非空控制载荷才是门禁回归。 |
| 有接口没有网页界面 | 该本地仓库副本只整理了后端；`/docs` 是接口文档，不是业务前端。 |

验收分四层：①语法、离线测试、6674 条数据装配；②HTTP 启动、分析及审计；③真实模型、资源与场景效果；④隔离环境下设备协议和人工审批。不能用前一层通过来证明后一层完成。
