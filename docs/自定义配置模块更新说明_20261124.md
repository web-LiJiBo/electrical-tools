# 自定义配置模块更新说明

日期：2026-11-24。此次修改仅在本地，未上传。

## 使用方式

首页原来的设备录入、指令模板管理入口，合并为“自定义配置”。

- **补充设备**：填写设备身份和所属场景，勾选已有指令；也可在当前窗口新增指令，返回后自动勾选并补齐所需字段。
- **补充指令**：填写动作、字段及前置条件，勾选多台兼容设备；也可在当前窗口新建设备，返回后自动关联。
- 子窗口的修改暂存在外层窗口内。外层取消时一起撤销；外层提交后进入主草稿。
- 全部配置先“校验并预览”，核对后“确认保存”。同一条指令可被多台设备共用；同一设备同一动作不能同时关联两条冲突指令。
- 普通刷新保留草稿。“放弃草稿并重载”可在版本冲突时重新读取最新配置；有需要的修改可先导出备份。

## 保存与兼容

设备、指令、关联分别保存为一份统一配置，避免双向编辑造成重复定义。配置文件为 `data/simulation/customization.json`，不随代码提交。保存失败会回滚，旧确认令牌不能覆盖新修订。

设备归属唯一具体场景；自动汇总使用相同身份和运行状态。保存更新目录和动作信息，同时保留会话的当前设备状态、运行事实及原设备协议映射。新配置启动时自动加载。旧设备导入及旧高级模板保存也保留统一配置。

旧页面地址转入新模块相应工作区；高级协议模板入口保留在模板目录中。

## 当前范围

结构化新增沿用已有手工配置支持的三类设备：调度机组、无功补偿装置、冷却风机。启停、有功/无功调整、电压调整、功率上限等动作按设备类型选择，新增指令可分别配置字段和条件。

其他已有设备及协议模板仍可查询；原有设备的高级协议模板补充功能保留。新自定义设备在统一模块的“指令”工作区维护，不从旧高级表单重复管理。

此模块负责模拟配置及动作定义，不改变既有报文生成能力，也不自动向实际设备下发。保存配置、查询、生成候选均不等于执行动作。
