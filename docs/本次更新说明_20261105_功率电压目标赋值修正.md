# 功率、电压目标赋值修正

更新日期：2026-11-05。

本次修正首页模拟操作中“已经明确写出功率或电压目标，却被当成附加条件拒绝”的问题。用户可以直接在问题中给出目标值，后端将其换算为设备模板要求的单位，核对后生成操作预览。

## 使用者能看到什么变化

在首页选择“新能源并网”，保持“使用模拟设备状态进行指令生成”勾选，业务参数保留为 `{}`，输入以下问题后点击“分析问题”：

| 用户输入 | 修改前 | 修改后 |
| --- | --- | --- |
| 将新能源逆变器（IEC61850）的有功功率设为120kW | 模型正确识别目标，后端却提示附加条件尚未编译 | 生成目标有功功率为120kW的模拟预览 |
| 将新能源逆变器（Modbus）的输出电压设为400V | 目标赋值被附加条件检查拦截 | 生成目标电压为400V的模拟预览 |
| 将新能源逆变器（Modbus）的有功功率设为0.12MW | 无法正常生成带目标值的预览 | 换算为模板使用的120kW后生成预览 |
| 将新能源逆变器（IEC61850）的无功功率设为30kvar | 等值约束被当成附加条件 | 生成目标无功功率为30kvar的模拟预览 |

这些示例对应项目预置模拟设备；能否生成仍须满足各设备模板的范围、参数类型和联锁要求。预览可以在原“操作建议”页签中查看，生成预览不会修改设备状态。只有明确点击“模拟下发”才执行模拟操作，真实设备下发仍关闭。

## 参数如何处理

1. 根据已选设备及动作模板识别目标字段，兼容“有功功率”“输出电压”等中文名称。
2. 将正文数值、模型理解出的数值统一换算到模板单位，例如0.12MW、120000W均对应120kW。
3. 有业务参数时，将其与正文、模型理解结果核对；数值不同不选择其中一个继续操作。
4. 正文已经给出明确目标、业务参数未填写时，自动补齐对应动作参数。
5. 核对完整数值与单位，处理千分位、特殊负号，区分mW与MW；不将120kW/s等不兼容的复合单位截成120kW。模型理解与正文存在差异时阻止预览。

## 哪些请求仍会被阻止

| 请求情况 | 处理方式 |
| --- | --- |
| 正文要求120kW，业务参数填写 `{"action_parameters":{"power_kw":130}}` | 提示目标值冲突，不生成可执行预览 |
| “只有并网允许时，才将逆变器有功功率设为120kW” | 保留条件式请求限制，不生成丢失条件的预览 |
| 要求1500kW，超出该逆变器模板的允许范围 | 由模板校验阻止 |
| 正文与模型解释的数值、正负号或单位不一致 | 阻止生成，要求明确目标 |
| 参数为布尔值、非有限数值或不兼容单位 | 阻止生成 |

否定、多步骤、整数档位、设备联锁及状态版本校验继续生效。新增中文目标别名仅在已完成本次数值核对的直接操作入口放行，避免扩大其他建议入口的条件豁免。
