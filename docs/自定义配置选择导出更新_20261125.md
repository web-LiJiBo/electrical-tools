# 自定义配置选择导出

日期：2026-11-25。本地更新，尚未上传。

“自定义配置 → 批量导入 / 导出”新增“选择导出自定义配置”区域，可逐项勾选自定义设备、指令，支持全选和清空。导出的是当前工作区，包含未保存草稿；原有“导出当前草稿”完整备份入口保留。

选择设备时带上它的直接关联和指令；选择指令时带上适用设备和直接关联。完整报文配置保存在关联中一起导出。自动补入的设备不会继续扩展其余无关指令，避免把整张关联网络全部导出。页面显示实际导出的设备、指令和关联数量。

JSON继续使用现有devices、instructions、bindings格式，可走既有合并导入、冲突预览及校验保存流程。预置设备和指令以原编号引用，不复制整个预置库，目标环境需有对应编号。条款使用独立导入格式，本次选择导出不包含条款。导出不会发布草稿、改变设备状态或使会话失效；未完成草稿仍需补齐配置后校验。

验证：65项相关前端测试通过，其中新增4项选择和依赖测试。隔离浏览器实际验证逐项选择、全选、清空及下载按钮；下载内容为1台设备、2条指令、2项完整报文关联，经现有合并与编译校验通过，两个新动作均保留。测试未修改正式配置，未调用问答模型（本次只改本地文件导出）。
