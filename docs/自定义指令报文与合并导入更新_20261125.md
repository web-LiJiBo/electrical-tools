# 自定义指令报文与合并导入更新

日期：2026-11-25。仅本地修改，尚未上传。

## 使用变化

- 新增或补充候选指令时，必须同时配置通信、写入点位和独立读回映射。按“具体设备＋动作”保存报文配置，共享逻辑指令的设备仍各用自己的地址和点位。
- 协议固定参数和适用的数据类型由表单带出；设备地址及实际点位由使用者补充。Modbus TCP与IEC61850/MMS均使用现有编码器检查能否生成完整请求包。缺配置、错误类型、错误单位、无效字节序或无法表达目标范围时拒绝发布。
- 批量导入改为合并预览：新编号新增，相同内容去重；同编号不同内容、同设备同动作的不同指令需要明确选择。确认前不覆盖主草稿，合并完成后仍须全量校验和确认保存。
- 冲突选择导致某指令失去所有关联时，预览明确列出不保留的定义；仍被其他设备共用的指令不移除。
- 成功保存后，配置页和已打开的问答页提示用户手动刷新，保留当前答案、输入和草稿供阅读或导出。旧会话引用、候选与报文生成凭据失效；后台清除旧会话及默认会话引用，手动刷新后须重新问答。失败时不清除草稿和当前会话。

## 兼容

旧配置仍可加载查看；缺报文时提示补齐，不能原样新发布。原高级模板入口支持一起提交完整wire，旧风机文件也支持单动作wire或多动作wires；历史文件加载保持兼容。没有自动替用户发明真实设备地址，也不执行设备动作。

## 后续审阅修正：通信端点、IEC标识与跨客户端刷新

- 点位冲突按通信主机与端口区分：不同端点允许相同点号，同端点仍核验重复。Modbus继续区分单元号与线圈/寄存器空间；IEC有完整MMS标识时按实际编码的域和变量名判断重复，避免长短对象引用绕过检查。
- 新增、修改报文时核对IEC对象引用与MMS域、逻辑节点及对象路径，防止显示目标和实际发包目标不一致。合法的短对象引用与带属性引用均可使用。
- 问答页在恢复焦点、从隐藏恢复可见时检查配置，可见页每15秒检查一次，识别其他浏览器或电脑的发布。重复请求合并，网络暂时失败保留当前内容并稍后重试。最新行为改为版本变化时只提示一次，停止继续轮询，由用户手动刷新。
- 本次74项后端、41项前端定向检查通过。Chrome真实页面验证独立客户端发布后的自动刷新，旧答案与模拟会话引用清除，无关会话存储保留。

## 最新调整：手动刷新与使用流畅性

- 所有窗口均改为非弹窗提示“配置已更新”，只点击“刷新并使用新配置”才重新加载。保留已有答案、未发送问题及配置草稿；旧候选、报文操作和新的问答暂停，刷新后重新问答。过期配置页仍可导出草稿，但不能发布旧配置。配置页保存后不再自动重新读取目录覆盖正在查看的内容。
- 发现并修正：分析、模拟与报文请求缺少超时可能永久锁住按钮。分析请求设置180秒上限，其余相关请求30秒；模拟执行超时仍按结果未确认处理，不自动重试。只读设备状态刷新不再延迟主操作按钮解锁。
- 发现并修正：每份报文参数异步返回都重建整个答案区，可能打断其他表单编辑。现在只更新对应表单；切换标签后请求返回时使用最新节点，避免卡在加载状态。
- 发现并缓解：批量执行后串行复核全部剩余候选导致等待累积。现在最多3项并行，每项开始前检查上下文；用户输入变化或配置过期后不继续安排旧任务。候选仍须基于最新状态复核，没有取消状态校验。
- 验证：49项前端组件检查、52项后端定向检查通过。真实Chrome确认配置更新后页面没有重载，答案和未发送输入保留，提示只出现一次，旧操作停用；点击刷新后恢复正常。真实接口的晚返回参数没有替换另一表单节点或焦点。
- 正常问答用一道真实DeepSeek组合题复测，2次模型调用，生成2条候选并回答2项状态查询；未执行指令。未重新遍历全部问法。本次未修改条款检索或模型识别算法，接口网络与模型响应耗时仍受外部服务影响。

## 自定义模板后续修正：仅本地保存

- Modbus按数据宽度检查整个地址占用范围，float32/int32/uint32占两个寄存器。同一通信端点、单元和地址空间的跨设备重叠，以及同一动作的写入与反馈重叠均拒绝；不同端点和不同地址空间继续独立使用。
- 未保存草稿改为当前窗口的sessionStorage，刷新可恢复，不同本地窗口互不覆盖。旧共享草稿首次打开时迁移到当前窗口；关闭窗口前可导出留存。确认保存后的配置仍在本地磁盘，不新增跨电脑同步。
- 解除最后一个关联时，明确确认是否同时删除孤立自定义指令；拒绝确认则不改变关联。提供“从草稿删除”入口；预置指令保持只读，不允许删除。若会使自定义设备失去全部指令，要求先关联替代指令。删除后只以当前草稿作为自定义指令来源，避免旧目录缓存将其重新显示。
- 原样保存仍检查校验凭据，但内容相同则不写文件、不更新配置版本、不清会话，也不提示刷新。只有实际变化保存成功后才使旧候选失效。
- 本轮76项相关后端和56项前端组件检查通过。真实页面验证原样保存版本不变、无刷新提示；解除启动指令最后一个关联后，停止指令保留并成功保存。真实DeepSeek用一道停止加状态查询组合题验收，2次调用、1条候选及1项查询，未执行。
- 扩展目录检查有2项既有断言不匹配：`test_catalog_preserves_all_legacy_devices_actions_and_mappings`仍要求归一化后映射完全等于旧映射；`test_substation_has_two_related_groups_seven_types_and_four_conditions`仍要求14台，而当前目录为18台。隔离禁用本轮点位校验后同样失败，未将它们计为本轮通过项，未改动相关断言。
- 本轮原始接口与浏览器记录保存在本地`06-工具/审阅记录/20261125_自定义模板审阅/`；测试设备未写入正式配置。
