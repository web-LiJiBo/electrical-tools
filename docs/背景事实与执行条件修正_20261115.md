# 背景事实与执行条件修改记录（2026-11-15）

基于已发布d20f52ba，本次更新未新增条款或正式模拟设备。

新增context_facts表示用户陈述，并保留参数、数值、单位、设备及原文；scenario.context_kind区分背景、执行前提、无工况及不确定。模型提示与结构校验同步，操作复核独立检查此分类，不能用背景掩盖真实执行前提。旧模型未声明背景分类时仍保持原限制，不直接忽略工况。

后台不再仅因背景工况非空而拒绝，已明确保留为背景的约束不作为指令前提。真正的conditions仍须白名单编译、预览/执行核验；带单位条件仅在设备明确声明fact_units且单位一致时匹配，不从字段名猜换算。未知字段/审批仍阻断。

用户陈述不写入当前状态；答复与context_fact_comparison分列用户值和当前原始字段值，单位及测量时点未核验时明确标记，不把用户阈值当标准。不会因用户说30MΩ就把当前3改成30。

模拟分支返回已登记场景名称，并标记条款检索是否发生；前端分别展示未检索、需澄清或条件校验未通过，避免一概解释为缺少条款。Python编译、内嵌页面脚本Node语法及差异空白检查通过。未运行受控模型作为业务验收，未实际操作浏览器界面。

## 真实API验收

第一轮17题暴露context_kind在输出schema中未显式列出及条件单位/作用域表达问题，失败样本原样保留。修订后的最终17题及3个反向问题合计20题、34次真实模型调用，未注入模型输出，无自动重试。所有状态不变，执行尝试0。

- 截图原句：背景分类，独立复核通过，生成alarm预览。
- 明确“低于10MΩ才告警”：条件被保留，当前3满足时生成受限预览。
- 只做检查：未生成操作；模型归入评估路径，返回当前值比较及正式依据不足说明，调用2次。本轮未将该比较单独优化为一次调用的纯状态入口。
- 用户描述30MΩ、当前3MΩ：分别展示，不覆盖状态；告警模板按当前事实核验。
- 简单海缆告警：正常预览。
- 低于2MΩ才执行：当前3不满足，无命令ID。
- 明确不要告警：无预览。
- 需主管审批但审批事实未知：阻断，无预览。
- 原12题同时真实回归，正常操作/查询继续返回；故障风机仍阻断，第二步调档仍未开放，正式试验判据仍说明资料不足。

海缆设备为隔离测试目录中从通用模板扩展的独立实例，只有测试目录保存。真实API不等于对方设备配置相同；未拿到对方导出的模板，尚未对其七条风电/线路/间隔操作逐题验收。没有验收真实设备或实际执行；Neo4j仍为配置允许的内存图降级。
