## 用户可见变化

1. **统一自定义配置**：设备录入与指令模板合并，可从任一侧新增并关联另一侧；指令与设备报文配置一并校验保存。批量导入先合并、预览冲突，再确认保存。
2. **新增动作模板**：可填写动作编号、名称、固定值或数值参数及范围、前置条件和结果字段，配置状态变化及Modbus TCP / IEC61850映射。每个动作目前控制一个值、改变一个结果字段；原模板继续兼容。模型读取动态目录中的新增能力。
3. **选择导出配置**：批量界面可勾选设备、指令，自动携带直接关联和完整报文配置，显示导出数量，支持全选、清空和重新导入；完整草稿备份保留。导出包含当前工作区未保存草稿，不自动发布。本地条款不混入设备配置文件。
4. **本地条款导入**：支持TXT正文和JSON批量条款，校验来源、重复与内容冲突，保存后参与检索与问答；不自动新增设备或绑定动作。用户设备配置、用户导入条款均留在本地，不随此次上传。
5. **问答及页面修正**：保留并列操作与真实执行依赖的区别、用户补参及单位换算；展示部分可生成与部分受阻。配置变化只提示手动刷新，保留正在查看的答案和输入，停用过期操作；完善超时、草稿隔离和局部表单更新。

默认新能源设备的字段说明、状态和停止后功率归零逻辑同步更新；场景实例身份独立，自动汇总沿用同一编号与状态，没有预置问答答案。
