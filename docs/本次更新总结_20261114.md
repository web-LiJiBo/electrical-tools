# 本次更新总结（2026-11-14）

本次基于主分支 `a9039694`，更新运维诊断、条件和顺序计划、来源说明与查询体验。真实设备下发保持关闭；查询和预览不改变设备状态。

## 主要变化

1. **当前动作条件诊断**：区分设备支持的动作与当前是否具备动作条件，逐台返回运行状态、供电、故障、检修闭锁等事实及满足/不满足/未知结果。
2. **只分析限制**：首轮模型保留整句限制及原文证据，后台阻止只分析请求生成指令。
3. **条件操作**：支持已登记字段的简单比较，预览与执行前均重新核验。复杂条件、未知字段及缺事实继续阻断。
4. **逐步反馈计划**：仅当前步骤可预览；前步成功反馈后，下一步仍须单独预览与确认。失败、未知反馈、版本或模板变化会停止后续步骤，不自动重试。
5. **减少正常查询误拦**：未完全覆盖的文字改为完整性提示并保留已确认结果；只读查询可承接同句唯一明确设备。取消操作、咨询问句和未保留的顺序要求仍受保护。
6. **来源用途分离**：建议可明确标为结论支持或限制说明。后者可引用本次检索中未采用的条款，解释不适用或资料缺口，单独保存在 `diagnostic_sources`，不能用于生成指令。
7. **撤销不受支持结论**：清理旧采用结论、引用和执行材料，同时保留经过验证的限制说明。未知来源ID、伪造引用及错误指令引用继续拒绝。
8. **温升结果去重**：混合事实与知识查询不再从两个路径重复附加同一温升评估；记录值与当前快照仍分别处理。
9. **检索适用性**：增加设备类型、试验主题、适用范围和来源身份检查，区分未召回与现有资料不足。
