# 通用设备模板、变电站模拟与动态指令转换更新说明

文档日期：2026-11-01。面向工具使用者及维护人员，记录此前本地完成、在本次一起发布的功能和文档。对比基准为 GitHub `main` 提交 [`b18889d2d00e3708ba4e09ce1ce2e9091106d675`](https://github.com/web-LiJiBo/electrical-tools/commit/b18889d2d00e3708ba4e09ce1ce2e9091106d675)，该版本发布于2026-10-27。

## 1. 本次解决什么问题

原版本可以查询标准、读取示例设备事实，并生成协议候选字段。本次将设备、动作和场景拆分为可复用配置，补齐变电站设备运维的模拟数据与关联关系，并使明确动作请求和条款分析后的模型建议使用相同的模板预览入口。

场景负责选择设备、描述关系和设置初始工况；设备的能力、动作参数和协议点位分别配置。不要求为每个场景复制指令，也不要求预先把一条指令绑定到某一条标准。

原首页和模板管理页的布局、样式、输入控件及原有页签保留。在原“操作建议”页签内，先查看预览，再明确点击“模拟下发”，才会改变当前会话中的模拟状态。真实设备下发始终关闭。

## 2. 与上一发布版本的差异

| 项目 | 基准版本 | 本次发布 |
| --- | --- | --- |
| 设备与动作组织 | 旧设备配置中保存具体动作及点位，按原场景和动作查找 | 新增设备模板、动作模板、设备实例、场景工况四层配置，兼容读取旧配置 |
| 设备目录 | 17台预置设备、41项设备动作 | 旧服务增加馈线后19台/47项；新通用目录合计25台/61项 |
| 变电站场景 | 示例设备事实和局部条款判断 | 两组主变设备关系，7类14台，四种工况，状态与操作均读取同一会话 |
| 普通查询 | 标准检索和示例状态判断 | 保留标准检索，增加当前设备状态、能力及多设备比较，不强制附带指令 |
| 明确动作 | 协议候选生成，不改变状态 | 通过共享模板预览，满足条件后可明确执行到独立模拟会话 |
| 条款建议转换 | 要求预置来源绑定及相应条款结构匹配 | 引用本次实际检索来源，设备动作按通用模板转换；不再要求静态绑定 |
| 运行反馈 | 生成后结束 | 增加模拟反馈、前后状态、状态版本、重复请求处理和历史事件 |
| 界面 | 原首页和模板管理页 | 保留原布局；仅在已有结果区域接入模拟操作及必要提示 |

此前已上传的标准编号、版本、来源补充以及新旧库统一查询属于基准版本，不重复计为本次新增。`datasets/` 下的原始库和补充条款JSON没有随本次功能改造修改；没有为满足转换要求而批量补写 `rules[].action`、`condition` 或 `constraint`。

## 3. 数量怎样计算

“设备动作”按一个具体设备的一种动作计数；同一种动作在IEC61850和Modbus两个设备实例上分别计数。“共享动作模板”按可复用定义计数，因此这两个数字不应相加或互换。

| 范围 | 设备/实例 | 设备动作 | 说明 |
| --- | ---: | ---: | --- |
| 上一发布基准 | 17 | 41 | 原有两个预置设备配置文件 |
| 本次纳入的此前馈线补充 | +2 | +6 | 两协议的馈线断路器，分别含分闸、合闸、告警 |
| 当前旧服务及原模板管理页 | 19 | 47 | 沿用旧接口；不包含新四层配置展开出的6台实例 |
| 本次新设备实例 | +6 | +14 | 两协议的隔离开关、接地开关及有载调压装置 |
| 新通用目录 | 25 | 61 | `/simulation/catalog`，保留旧设备并展开新模板 |
| 变电站主场景 | 14 | 场景中设备能力的子集 | 7类设备，每类2台；不是再增加14台 |

四个新增配置文件直接定义7种设备模板、13种动作模板、6台实例和2个场景。适配旧配置后，通用目录展示12类设备模板和29个共享动作模板。不能将“四个文件中直接定义的13个动作模板”理解为整个目录只有13项设备动作。

新增动作包括隔离开关分合、接地开关分合、调压升一档/降一档/设定档位，共7种动作组合，分别适配两种协议形成14项设备动作。断路器、冷却风机和油泵等已有动作通过兼容适配复用。主变本体提供测量和状态，操作通过其关联设备完成，不虚构主变本体的“启动/停止”动作。

## 4. 使用路径和功能边界

| 用户目的 | 处理方式 | 是否需要条款 | 是否改变状态 |
| --- | --- | --- | --- |
| 查询标准、条款含义 | 完整知识库检索和分析 | 需要实际检索依据 | 否 |
| 查询设备当前状态、可用操作、比较多台设备 | 当前模拟会话快照和目录 | 不要求命中条款 | 否 |
| 明确要求启动风机等动作 | 设备解析、动作参数与模板检查、生成预览 | 可不引用条款 | 预览不改变；明确执行才改变 |
| 根据条款分析并提出动作建议 | 实际来源和当前事实交给建议模型，再进行引用及模板检查 | 须引用本次真实检索结果，无需预绑定 | 分析和预览不改变；明确执行才改变 |
| 判断设备是否符合标准 | 原文适用性和可比对参数判定 | 需要适用原文，数据不足则说明 | 否 |

离线模式可以运行标准查询、当前模拟事实查询和明确动作的模板预览/模拟执行。自动提出动作的建议模型需要在线配置；离线测试中的模型替身只用于检验代码契约，不代表已评价在线回答质量。

温升判断仅针对代码能够解释并比对的来源参数，不等于设备整体健康评估；开启风机不会自动计算温度下降。四种工况、模拟编号、寄存器、联锁和反馈用于软件实验，不替代现场点表、完整电气过程或厂家协议。

## 5. 配置与代码定位

| 文件或模块 | 本次职责 |
| --- | --- |
| `configs/device_templates.json` | 通用设备类型、状态/事实规格、动作引用 |
| `configs/action_templates.json` | 共享动作参数、前置条件、关系联锁、模拟效果和逻辑点名 |
| `configs/device_instances.json` | 新实例的编号、协议、初始状态、模板引用和具体模拟点位 |
| `configs/scenario_profiles.json` | 场景所含实例、角色分组及工况覆盖值 |
| `configs/simulation_devices_supplement.json` | 保留此前补充设备，并纳入馈线断路器实例和动作 |
| `instruction_engine/simulation_catalog.py` | 合并新旧配置、展开模板、检查模拟地址和场景引用，提供目录 |
| `instruction_engine/simulation_runtime.py` | 隔离会话、预览、明确模拟执行、版本检查、反馈及事件 |
| `application/simulation_access.py` | 每个应用共享一个运行器，各会话状态隔离 |
| `application/simulation_query.py` | 当前设备事实问答、设备关系解析与明确动作预览 |
| `application/real_clause_assessment.py` | 真实条款局部参数判断使用当前会话事实 |
| `application/grounded_advice.py` | 建议模型输出及引用、目标、动作、参数和文字一致性检查 |
| `application/advice_conversion.py` | 将动态引用与当前快照交给通用模板预览，保留证据 |
| `api/simulation_routes.py` | 目录、会话、预览、执行、工况、重置和事件接口 |
| `frontend/original-simulation.js` | 复用原输入和页签，连接同一会话，控制明确执行及旧预览失效 |
| `frontend/simulation.html` | 兼容旧工作台地址，跳回原首页 |

上表省略的源码前缀为 `src/standard_knowledge_service_v2/`。原 `SimulationInstructionService.generate()` 和模板编辑页“测试生成”继续只生成协议示例，不更新会话状态。已有来源关联字段保留兼容读取，不再作为模型建议转换的静态绑定门槛。

## 6. 更新、启动与迁移

1. 保留使用者自己的 `.env`、自定义模板及运行记录。密钥和 `configs/custom_instruction_templates.json` 不在本次发布范围内。
2. 更新代码和随代码发布的配置后重启后端；通用目录在应用中延迟创建，不能仅刷新页面来代替重启。
3. 标准安装使用项目声明的Python 3.13，按README执行 `初始化项目环境.ps1`，再运行 `启动前端实验.ps1`；默认后端8000、前端5500。在线模式使用 `-Online` 并自行配置模型密钥。
4. 刷新原首页，选择变电站设备运维并保留模拟状态选项。输入问题后，在原结果页签查看回答和操作建议；仅点击“模拟下发”更新当前模拟会话。
5. 重启后旧内存会话不恢复，页面需重新建立会话；已持久化事件可凭旧会话编号只读查询，不会重放。工况切换和重置也可能改变当前会话状态，旧预览需重新生成。

本机开发验证曾使用前端5501和后端8001，页面URL通过 `?backend_port=8001` 选择后端。这是验证端口，不是默认启动脚本的端口；其他使用者无需照搬。

原模板管理页仍用于旧配置的查询和自定义动作补充；它没有新增四层配置的完整编辑表单。新增通用设备/动作/实例/场景应按[配置指南](变电站模拟工作台.md)修改相应JSON并重启，不应只在原编辑页查找新目录中的所有实例。

本次不涉及数据库结构迁移、标准JSON重写或项目依赖变更。事件文件 `data/simulation/events.jsonl`、页面验证截图、临时文件和本机IDE配置不随功能发布。

2026-11-01发布前重新执行完整离线测试：**416项通过、15项跳过、0项失败，134.44秒**。跳过项沿用历史批次、迁移及本地来源样例等前置条件，未把本次功能的失败改为跳过。原始记录为本机 `.tmp/release-20261101.log` 和 `.tmp/release-20261101.xml`；这些文件不纳入发布。

运行测试覆盖新旧目录兼容、无绑定转换、引用保留、参数边界、否定/未决/多动作建议、联锁缺失、会话隔离、状态版本变化、重复执行、反馈或日志失败，以及普通问答不执行等情况。本轮没有重新启动浏览器验证；上段14项浏览器结果仅指2026-10-31记录。

本机实际测试解释器为Python 3.12.14；项目声明及标准启动脚本仍要求Python 3.13。本次测试沿用本机已有的Excel可选依赖，通过临时 `PYTHONPATH` 载入，临时目录均在工作区。这证明当前代码在该验证环境下的结果，不冒充从零安装Python 3.13的验证；本次未更改环境脚本或放宽项目版本要求。

本轮文档核验：10份说明的72处本地文件链接有效，10个PowerShell代码块通过语法检查；实际执行使用指南的API示例，在独立的本地HTTP服务中新建会话、预览、明确启动风机并查询状态/事件，得到 `generated → succeeded`、状态 `false → true`、版本 `0 → 1`、1条事件，真实下发为 `false`。未使用现有用户会话。另直接核对聚合目录数量及原页面CSS/控件，与本文口径和保留原界面的要求一致。

独立读者审阅覆盖启动、数量区别、不绑定转换、查询边界、模型验证和重启历史；已修正文档对直接动作疑问识别范围的过度表述。直接动作分支是有限词组匹配，不能承诺理解所有问句；无论是否产生预览，实际模拟执行仍须明确操作。

发布前检查不调用在线建议服务，不评价模型建议的专业正确性，不连接真实设备，也不进行完整协议认证。需要增加标准时，仍应单独开展数据来源核验；模板校验成功不等于引用条款已完成专业审核。
