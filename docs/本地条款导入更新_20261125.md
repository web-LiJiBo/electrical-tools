# 本地条款导入更新

日期：2026-11-25。已随2026-11-25统一更新发布；以下为本地验证记录。

## 使用方式

进入“自定义配置 → 条款”。可以粘贴完整正文、选择TXT文件，或选择JSON文件批量导入。TXT整体作为一条正文，不自动猜测拆分。

每条须填写标准编号、版本、条款号和正文；标准名称、主体、关键词以及JSON中的动作、条件、约束可选。JSON中的字段优先于上方公共输入，每批最多100条、2MB，单条正文最多20000字符。页面提供JSON格式模板。

先点击“校验并预览条款”，核对后点击“确认导入条款”。同一标准编号、版本和条款号：正文相同去重并保留原辅助信息；正文不同列出已有与本次内容，整批不保存。输入改变后原预览失效，须重新预览。

本地文件为`data/knowledge/local_clauses.json`，不覆盖原标准数据集，重启后恢复。导入完成立即参与后续检索、问答和条款分析，不自动增加设备、创建动作或绑定指令，不改变已有设备状态和会话，也不强制刷新已有答案。

JSON支持单条对象、对象数组，或`{"clauses":[...]}`。每条允许字段：`standard_id`、`standard_name`、`version`、`clause_number`、`content`、`subject`、`keywords`、`action`、`condition`、`constraint`。关键词使用文本数组，其余使用文本。未知字段明确提示，不静默丢弃。

## 实现及验证

- 新增本地条款服务及预览/导入接口，批次校验与索引准备成功后原子保存本地文件，再发布运行引用；失败不改变旧仓库及图谱。
- 新增条款采用增量检索索引和图谱，不重建整个知识库。外部图谱使用本地叠加层，导入期间不写外部数据库、不新建连接池；关闭服务时仍释放原图谱资源。
- 原样/重复导入不写文件、不更新索引。预览凭据绑定当前本地条款及本批内容，期间发生其他导入时要求重新预览。
