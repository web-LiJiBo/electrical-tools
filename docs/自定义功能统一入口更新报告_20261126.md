# 自定义功能与统一配置入口更新报告

日期：2026-11-26。基于线上main提交`6594343c`，汇总本轮自定义功能审阅、修正、开放登记及页面整合。

## 本次变化

1. **通信修改展示整机影响**：更改设备通信地址或恢复原配置时，列出新旧通信信息及全部受影响动作，勾选确认后才能保存。新增设备、通信未变化时不增加确认步骤。
2. **完善点位冲突检查**：核对同一设备不同动作之间的写入、反馈、字段及编码关系，覆盖32位寄存器部分重叠。相同状态和编码的启停共享点位继续允许，Modbus各类地址空间分别处理，避免误拦合法配置。
3. **开放设备类型、别名与单位登记**：支持用户登记业务类型、设备别名和单位。单位可仅作标记，也可填写明确的基准、倍率和偏移；换算用于目标值规范化及用户补充当前值。别名进入设备目录并参与身份识别。
4. **登记合并到设备和指令表单**：类型、单位选择旁直接新增并回选，不再使用独立登记页面。保留输入；取消外层表单时，同时撤销其中新增的登记。登记内容仍统一保存和复用。
5. **移除旧高级协议模板界面**：统一走“新增指令 → 选择已有设备 → 定义动作和字段 → 配置报文 → 校验保存”。原有换流阀、储能、开关等设备类型均可在统一入口选择。
6. **已有设备可补充动作所需字段**：缺少的字段及默认值在关联提示和保存预览中展示，保存后补齐。原有动作、通信和点位继续保留，不修改原设备身份或所属场景。
7. **配置与资料同步**：类型、单位登记及别名随配置保存，批量导入预览冲突，选择导出携带必要登记及换算依赖；保留单独导出登记内容的按钮。正常问题清单仍按16组组织，增加本轮真实API通过记录，附录现有206条来源记录。

## 页面及兼容

- 使用`frontend/customization.html`中的设备、指令、模板目录和批量工作区。
- `customization-advanced.html`和`template-editor.html`仅保留轻量地址跳转，原表单及固定动作列表已删除，旧地址进入统一指令工作区；测试端口参数继续保留。
- 旧`tab=definitions`地址进入设备工作区。
- 已保存的旧模板仍由后端兼容加载，没有删除用户配置文件。旧版三数组配置文件继续兼容，新登记通过可选`definitions`保存。
- 配置仅在本地保存；导入和保存后提示手动刷新，不自动刷新正在阅读的答案。

## 仍保留的边界

- 动作目前是一个控制值、一个主要结果字段；复杂分支、多参数、多报文工作流、任意脚本和自动下发未开放。
- 字段类型、范围、单位关系、身份唯一性和报文编码继续校验。已有字段及已使用单位的含义不能静默改变；相互矛盾的新增字段定义不能保存。
- 设备类型登记不自动赋予动作或点位；单位登记不代表程序已核实用户填写的物理关系，未登记换算时不猜倍率。
- 新类型、单位各最多100项，设备别名最多20个；原有配置数量、字段和文件大小限制继续保留。
- 本轮未增加跨电脑同步，也未接入实际电力设备。
