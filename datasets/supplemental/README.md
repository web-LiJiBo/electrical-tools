# 补充条款发布快照

本目录独立于原标准库 `datasets/lunwen/verified_json/json`。

- `分解数据/json`：2026-10-12准备发布的46,466份补充条款JSON，保留标准名称、编号、章节、原文、规则和审查标记，文件名为 `standard_id chapter_path.json`。
- `子条款`：对应的原文索引和来源索引摘要，用于来源追溯，不参与运行时的规则库装配。
- `publish_manifest.json`：快照数量、校验及范围说明。

当前在线/离线配置直接读取本目录的JSON，不要求仓库外的中文目录存在。原始Excel、读取中间文件、连续分批队列和助手批次标注未纳入这次快照；它们仍保存在原本地工作目录，不能把本快照当成完整分解过程归档。

条款语义初稿不等于已通过领域专家审查、有效规范或控制授权；保留的 `metadata.audit.manual_review_required` 会参与安全检查。不得因为数据被发布就放宽生成门禁。
