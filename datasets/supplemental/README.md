# 补充条款发布快照

本目录独立于原标准库 `datasets/lunwen/verified_json/json`。

- `分解数据/json`：46,466份补充条款JSON；2026-10-26在原快照上补充标准身份、版本年份和来源元数据。文件名保留历史名称，当前标准编号以JSON中的`standard_id`为准。
- `子条款`：对应的原文索引和来源索引摘要，用于来源追溯，不参与运行时的规则库装配。
- `publish_manifest.json`：快照数量、校验及范围说明。

当前在线/离线配置直接读取本目录的JSON，不要求仓库外的中文目录存在。原始Excel、读取中间文件、连续分批队列和助手批次标注未纳入这次快照；它们仍保存在原本地工作目录，不能把本快照当成完整分解过程归档。

条款语义初稿不等于已通过领域专家审查、有效规范或控制授权；保留的 `metadata.audit.manual_review_required` 会参与安全检查。不得因为数据被发布就放宽生成门禁。

## 2026-10-26来源元数据补充

全部46,466条记录已补齐原始Excel的来源文件、工作表、行号和单元格坐标；45,175条具有可确认的标准编号或内部文号及其年份；40,368条关联了适用范围原文。2,576条具有唯一的PDF全文精确匹配页码，另46条保留多个匹配位置，不自动选定页码。

- `标准来源目录.json`：146份来源文档的标准身份、版本依据、范围摘录、原始文件哈希和PDF可检索状态。
- `元数据补充汇总.json`：本次处理数量、内容保护检查和验证结果。
- `标准元数据待核验清单.json`：仍无正式编号或缺少适用范围原文的文档清单。

条款的`metadata.source_location`记录逐条坐标，`metadata.standard_metadata`引用来源目录，`metadata.applicability`分别记录标准范围引用与原有条款条件。范围摘录仅补充证据，尚未编译为适用性判断或控制前置条件。年代号不是实施日期，也不表示已经统一核验现行有效性。

11份内部制度的来源文件名没有正式编号，对应1,291条记录的`standard_id`和`version`留空，原误填值保存在`metadata.original_standard_id`。所有记录都保留原规则、专家复核状态和内部标识；原始索引及历史文件名保持不变。详细说明见[第二批标准元数据补充说明](../../docs/第二批标准元数据补充说明_20261026.md)。本次发布包含新库数据与共同查询分析适配；原始文件、备份和运行记录不纳入版本管理。

## 新旧库共同查询与分析（2026-10-27）

当前目标是让补充库与原库共同参与标准查询、条款解释和文字分析。新库不要求先补齐设备动作码、可执行控制条件或协议模板；业务操作、自然语言条件及约束可以继续保留为文字。旧库6,674条与新库46,466条共用同一检索和分析流程。

知识查询按来源正文进行相关性排序，不因条款缺少设备动作字段而降低其动作匹配分；查询分解产生的英文动作码不作为原文中英文术语的字面命中。已标注为“仅标题”的记录继续保留在库中供来源导航，但不作为正文回答。询问适用范围时，从已有正文中查找范围表述，不从新增元数据推测答案。

在线文字分析取决于建议模型配置；离线模式可以检索并引用来源。能检索到条款不代表已完成领域审定，原审核标记继续保留。只有明确的候选指令生成请求才使用动作匹配与相应生成门禁。
